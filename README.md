# Веселовская — сайт и файлы для GitHub Pages

Статический сайт ассистента «Веселовская» плюс готовые файлы для скачивания.
Никакого сервера не нужно: GitHub Pages отдаёт эту папку как есть.

## Что внутри

| Файл | Что это |
|---|---|
| `index.html` | Главная страница: описание, примеры, кнопки скачивания |
| `veselovskaya-2.2-kit.zip` | Комплект 81 КБ: установщик для Windows/macOS/Linux, инструкция, шпаргалка |
| `veselovskaya-2.2.pyz` | Один файл 63 КБ — запуск без установки |
| `files/` | Те же файлы по отдельности, со своей страницей-списком |
| `og.png` | Превью для соцсетей (1200×630) |
| `favicon.svg` | Иконка сайта |
| `robots.txt` | Разрешает индексацию страниц, прячет архивы |
| `.nojekyll` | Отключает Jekyll — файлы отдаются ровно в таком виде |
| `set_url.py` | Необязательный шаг: прописать настоящий адрес сайта |

## Публикация

Пошагово — в `КАК-ЗАЛИТЬ.md`. Коротко: создать публичный репозиторий,
загрузить содержимое этой папки, включить Pages (Deploy from a branch → `main` → `/ (root)`).

Адрес получится такой: `https://<логин>.github.io/<репозиторий>/`

## После публикации (по желанию)

Прописать адрес, чтобы поисковики и мессенджеры видели канонический URL:

```bash
python3 set_url.py https://<логин>.github.io/<репозиторий>
```

Скрипт добавит `canonical`, `og:url`, абсолютный `og:image`, `sitemap.xml`
и строку `Sitemap:` в `robots.txt`. Повторный запуск безопасен.

## Про файлы

- Всё, что нужно для работы, — внутри архива и `.pyz`. Сайт не собирает данные
  и не отправляет ничего на сервер: JS только переключает вкладки.
- Версия 2.2.0, лицензия и подробности — в `files/README.md` и `files/CHANGELOG.md`.
- Те же материалы лежат на зеркале: <https://veselovskaya-files.surge.sh/>
