Модель для свободных текстов

Расчёты считаются здесь, на странице. Всё остальное — обычный чат: письма, объяснения, переводы, код, любые вопросы. По умолчанию работает бесплатный режим без ключа; можно вставить свой ключ — тогда запросы идут напрямую из браузера в выбранный сервис.

В бесплатном режиме запросы идут через сервис Pollinations: он не требует ключа, но может ограничивать частоту и не гарантирует постоянную доступность. Для стабильной работы подключите свой ключ.

Локальный движок: арифметика детерминированная, без модели. Ответы воспроизводимы.
