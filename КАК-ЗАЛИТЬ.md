# Как выложить сайт на GitHub Pages

Нужен аккаунт GitHub (бесплатный). Репозиторий должен быть **публичным** — на
бесплатном тарифе Pages работает только в публичных. Ничего оплачивать не надо,
кредитная карта не требуется.

Зальёте один раз — обновлять потом можно тем же способом (загрузить новые файлы
и закоммитить).

---

## Способ 1. Через сайт GitHub, без программ (проще всего)

1. Откройте <https://github.com/new>.
2. **Repository name**: `veselovskaya` (можно любое, но без пробелов — это попадёт в адрес).
3. Выберите **Public**. Галочки «Add README», «.gitignore», «license» — **не** ставьте.
4. Нажмите **Create repository**.
5. На пустой странице репозитория — ссылка **uploading an existing file**
   (или кнопка **Add file → Upload files**).
6. Распакуйте архив `veselovskaya-github-pages.zip` на компьютере.
   Откройте папку `veselovskaya-pages` и **перетащите в браузер её содержимое**
   (файлы и папку `files`), а не саму папку. Важно, чтобы `index.html` лежал
   в корне репозитория, а не внутри вложенной папки.
7. Внизу — **Commit changes**.
8. В репозитории: **Settings** (шестерёнка сверху) → слева **Pages**.
9. Блок **Build and deployment**:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main`, папка `/ (root)` → **Save**.
10. Подождите 1–3 минуты, обновите страницу Pages — сверху появится адрес:

    `https://<ваш-логин>.github.io/veselovskaya/`

    Он же будет в блоке Pages зелёной плашкой «Your site is live at…».

Готово. Первая сборка иногда занимает до 10 минут — если сразу 404, подождите
и обновите с Ctrl+F5.

### Мелочи, которые стоит знать

- **Ссылка вида `https://<логин>.github.io/veselovskaya/`** — со слэшем на конце.
  Без слэша GitHub сам перенаправит, это нормально.
- **Скачивание работает сразу**: кнопка «Скачать комплект» отдаёт
  `veselovskaya-2.2-kit.zip` (81 КБ), рядом — `.pyz` (63 КБ).
- **Скрипты для Linux/macOS** на GitHub теряют бит «исполняемый». Если
  `./start-linux.sh` не запускается — выполните `bash start-linux.sh`
  или `chmod +x start-linux.sh` перед запуском. В архиве из кнопки на сайте
  бит на месте.
- Ограничение Pages: 1 ГБ на сайт, 100 ГБ трафика в месяц — здесь 0,4 МБ,
  упереться невозможно.

## Способ 2. Через git, если он уже стоит

```bash
cd veselovskaya-pages
git init -b main
git add .
git commit -m "Веселовская 2.2: сайт и файлы"
git remote add origin https://github.com/<логин>/veselovskaya.git
git push -u origin main
```

Дальше включите Pages: **Settings → Pages → Deploy from a branch → main / (root) → Save**.

Обновление в будущем: заменить файлы, `git add . && git commit -m "обновление" && git push`.

## После публикации: прописать настоящий адрес (по желанию)

Пока адрес не прописан, страница всё равно полностью работает — все ссылки
внутри относительные. Но для поисковиков и превью в мессенджерах полезно
указать канонический адрес. Если на компьютере есть Python:

```bash
python3 set_url.py https://<логин>.github.io/veselovskaya
```

Скрипт добавит `canonical`, `og:url`, абсолютный `og:image`, создаст
`sitemap.xml` и допишет строку `Sitemap:` в `robots.txt`. Запускать можно
сколько угодно раз — дублей не будет. Потом загрузите изменённые файлы
(`index.html`, `robots.txt`, `sitemap.xml`) в репозиторий.

Без Python: можно просто открыть `index.html` в блокноте и вставить
`<link rel="canonical" href="https://<логин>.github.io/veselovskaya/">`
перед `</head>` — остальное необязательно.

## Свой домен (если появится)

**Settings → Pages → Custom domain** → вписать домен → у регистратора добавить
`CNAME`-запись на `<логин>.github.io` → поставить галочку **Enforce HTTPS**
(сертификат GitHub выдаёт бесплатно, обычно за несколько минут).

---

## Чего этот сайт не делает

- Не собирает почту, не ставит cookie, не подключает аналитику и внешние скрипты.
- Не хранит файлы пользователей: всё скачивается статикой.
- Единственный внешний запрос — тот, что делает ваш браузер при скачивании архива.

## Если что-то не так

| Симптом | Причина и что делать |
|---|---|
| 404 на главной | Pages ещё собирается (1–10 мин) или выбран не тот branch/папка |
| 404 на картинках, «голая» страница без стилей | при загрузке получилась вложенная папка: `index.html` должен лежать в корне репозитория |
| В репозитории видно `Скачать` вместо файлов | нормально: `.md` GitHub показывает как текст, архивы — как файлы |
| Страница есть, но поиск не находит | новому сайту нужно время (дни), плюс помогает `set_url.py` и `sitemap.xml` |
| Хочу обновить версию | заменить `veselovskaya-2.2*.{pyz,zip}`, `files/*`, закоммитить |
