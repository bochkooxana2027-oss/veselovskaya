# История версий

## 2.2.0 — «на компьютер»

- Установщик для трёх систем: `start-windows.bat`, `start-macos.command`, `start-linux.sh`.
  Один двойной клик: проверит Python, соберёт окружение в `~/.veselovskaya`, поставит
  зависимости и откроет ассистента в браузере. Повторный запуск — сразу.
- `serve --open` — сам открывает браузер; если порт занят, берёт следующий и печатает адрес.
- Веб-чат по умолчанию слушает только `127.0.0.1` (раньше `0.0.0.0`): чужие в локальной
  сети не попадут. Для сервера — `HOST=0.0.0.0`.
- Ярлык на рабочем столе (Windows) и пункт в меню приложений (Linux) создаются сами.
- `УСТАНОВКА.md`: пошагово для Windows/macOS/Linux, обновление, удаление, разбор сбоев.
- Расчёты понимают разговорные суммы: «млн», «миллион», «тыс», «к». Раньше
  «ипотека 3 млн на 15 лет под 12%» считалась кредитом на 3 рубля — платёж 0,04.
- «50к минус 20%», «300 плюс 15%» — изменение суммы на процент.
- 6 новых тестов (45 всего) на разговорные суммы и единицы измерения.

## 2.1.0 — «бесплатно»

- Бесплатные LLM из коробки: OpenRouter, Groq, Google Gemini, Mistral, Cerebras
  и локальная Ollama. Ключ с бесплатного тарифа подхватывается автоматически.
- `python -m veselovskaya providers` — список бесплатных вариантов, их лимиты,
  ссылки на получение ключа и что уже найдено в окружении.
- Порядок подбора: своя настройка → ключ из окружения → локальная Ollama → офлайн.
  Отключается через `VESELOVSKAYA_FREE=0`, фиксируется `VESELOVSKAYA_PROVIDER`.
- Локальная модель работает без ключа: `llm_ready` учитывает провайдера без авторизации.
- Веб-чат показывает, чем работает: «бесплатно: Groq», «локальная модель», «офлайн-режим».
- 20 новых тестов (39 всего): подбор провайдера, приоритеты, отключение, офлайн-фолбэк.

## 2.0.0 — «готовый продукт»

- Новый веб-чат: рендер markdown (таблицы, списки, код), копирование ответа,
  карточки файлов, индикатор режима (офлайн/LLM), «Новый чат», адаптив.
- Один файл `veselovskaya.pyz` — запуск на любой машине с Python 3.9+ без установки.
- `./install.sh` и `./start.sh` — установка и запуск одной командой.
- `python -m veselovskaya doctor` — понятная проверка окружения (✓/•/✗).
- `ПАМЯТКА.md` — одна страница «как начать» для человека, а не для разработчика.
- README: раздел «Три способа запуска».
