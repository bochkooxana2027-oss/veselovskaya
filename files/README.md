# Веселовская

Универсальный ассистент: тексты, расчёты, контент, дизайн, код, обучение, маркетинг, видео.
Не «одна модель, которая всё умеет», а **оркестратор специалистов** — по-другому это и не работает.

```
запрос → роутер → специалист → результат (+ файлы)
```

---

## Почему не «обучить одну сеть на всё»

Маленькая модель на 5 МБ текстов физически не умеет рисовать, считать и писать код: у неё нет
для этого ни архитектуры, ни данных, ни инструментов. Считать «на глазок» она к тому же будет
ошибаться — это свойство языковых моделей, а не баг.

Поэтому правильно так, как сделано здесь:

| Задача | Кто выполняет | Почему так |
|---|---|---|
| Арифметика, проценты, кредит | детерминированный вычислитель (AST + формулы) | ноль ошибок, работает офлайн |
| Контент-план | алгоритм распределения рубрик | предсказуемо, повторяемо |
| Лендинг, API, SQL | генератор кода + шаблоны | отдаёт рабочий файл, а не «пример» |
| Свободный текст | LLM (любой OpenAI-совместимый) | гибкость языка |
| Картинки | провайдер изображений | отдельная модель |
| Видео | раскадровка + промпт | видео — отдельный тяжёлый конвейер |

Роутер выбирает специалиста по ключевым фразам за микросекунды и бесплатно.
Ошибся — можно указать скилл вручную: `--skill calc`.

## Установка на компьютер (для человека, а не разработчика)

Скачайте архив с сайта, распакуйте, запустите файл под свою систему:

| Система | Файл | Что делает |
|---|---|---|
| Windows 10/11 | `start-windows.bat` | двойной клик: ставит окружение, открывает браузер, кладёт ярлык на рабочий стол |
| macOS 12+ | `start-macos.command` | то же (или `bash start-macos.command` в Терминале) |
| Linux | `start-linux.sh` | `bash start-linux.sh`, пункт появится в меню приложений |

Нужен только **Python 3.10+** и интернет на первый запуск. Ставится в `~/.veselovskaya`
(Windows: `%LOCALAPPDATA%\Veselovskaya`), около 60 МБ. Подробно — `УСТАНОВКА.md`.

## Три способа запуска (для тех, кто дружит с терминалом)

**1. Один файл — вообще ничего устанавливать не нужно** (Python 3.9+):

```bash
python3 veselovskaya.pyz ask "15% от 4800"
python3 veselovskaya.pyz chat
```

**2. Веб-чат одной командой:**

```bash
./install.sh     # один раз: .venv + зависимости + .env
./start.sh       # поднимает сервер и открывает браузер на 127.0.0.1:8000
python3 veselovskaya.pyz serve --open   # то же самое без установки, если есть fastapi
```

**3. Docker:**

```bash
docker build -t veselovskaya . && docker run -p 8000:8000 --env-file .env veselovskaya
```

Проверка окружения в любой момент: `python3 -m veselovskaya doctor` — покажет, что
уже работает (✓), что можно улучшить (•) и что сломано (✗). Для человека, а не для
разработчика, есть `ПАМЯТКА.md` на одну страницу.

## Быстрый старт (без ключей и интернета)

```bash
cd veselovskaya
python3 -m veselovskaya ask "15% от 4800"
python3 -m veselovskaya chat
```

Офлайн-режим полностью работает для: расчётов, контент-планов, лендингов, каркаса API,
промптов для картинок, раскадровок видео, выжимок из текста, чек-листов, маркетинг-каркаса.
Свободные тексты без LLM отдаются структурным каркасом — это честно помечается в ответе.

## Бесплатно — по умолчанию

Свободный текст можно писать бесплатно: у большинства провайдеров есть тариф,
на котором выдают обычный API-ключ. Аккаунт бесплатный, карта не нужна.

```bash
python3 -m veselovskaya providers     # что бесплатно и что уже найдено
```

| Вариант | Ключ в окружении | Что даёт |
|---|---|---|
| OpenRouter | `OPENROUTER_API_KEY` | модели с суффиксом `:free`, ~50 запросов в день |
| Groq | `GROQ_API_KEY` | щедрый лимит, очень быстрые ответы |
| Google Gemini | `GEMINI_API_KEY` | бесплатный уровень, лимит в минуту |
| Mistral | `MISTRAL_API_KEY` | бесплатный план Experiment |
| Cerebras | `CEREBRAS_API_KEY` | бесплатный уровень, быстрая выдача |
| Ollama (локально) | не нужен | совсем бесплатно и без интернета |

Подбор автоматический, в этом порядке: ваша собственная настройка → ключ из
окружения → живая локальная Ollama → офлайн-каркас. Ключ достаточно положить
в `.env`, перезапуск не нужен:

```bash
echo 'GROQ_API_KEY=gsk_ваш_ключ' >> .env
python3 -m veselovskaya doctor        # покажет: «бесплатный тариф Groq · модель …»
```

Выбрать конкретного провайдера или выключить автоподбор:

```env
VESELOVSKAYA_PROVIDER=groq     # openrouter | groq | gemini | mistral | cerebras | ollama
VESELOVSKAYA_FREE=0            # не искать бесплатное, работать строго офлайн
LLM_MODEL=qwen/qwen3-235b-a22b:free   # своя модель вместо модели по умолчанию
```

Честно о лимитах: бесплатные тарифы ограничивают частоту запросов, а названия
бесплатных моделей у OpenRouter периодически меняются — если модель пропала,
поставьте любую другую с суффиксом `:free` через `LLM_MODEL`. При ошибке
провайдера ассистент не падает: отдаёт офлайн-результат и пишет причину в пометках.

## Своя модель (OpenAI / DeepSeek / локальный сервер)

```bash
cp .env.example .env
# впишите LLM_API_KEY, если хотите платную модель или свой прокси
./run.sh ask "напиши пост про открытие кофейни"
```

Любой OpenAI-совместимый провайдер, включая локальные:

```env
LLM_BASE_URL=http://localhost:11434/v1
LLM_MODEL=llama3.1
LLM_API_KEY=ollama
```

Генерация картинок — через `/images/generations`:

```env
IMAGE_BASE_URL=https://api.openai.com/v1
IMAGE_API_KEY=sk-...
IMAGE_MODEL=gpt-image-1
```

## Примеры: запрос → ответ

Ниже — реальные ответы в офлайн-режиме (без ключей). Фрагменты сокращены, но цифры и структура настоящие.

**1. Расчёт — всегда через вычислитель, никогда «на глазок»**

```
> скидка 30% на 12 500

**Скидка 30% на 12 500**
- Итоговая цена: **8 750**
- Экономия: 3 750
```

**2. Контент-план — таблица + CSV, без «вдохновения»**

```
> контент-план на 7 дней для кофейни в телеграме

# Контент-план: кофейня
| Дата | День | Рубрика | Формат | Тема | CTA | Время |
| 15.11.2026 | Вс | Личное | кадр за кулисами | личное: кадр за кулисами — кофейня | Поставьте реакцию, если близко | 09:30 |
| 16.11.2026 | Пн | Вовлечение | вопрос подписчикам | ... | Ответьте одним словом | 09:30 |
```

На выходе ещё `content-plan-telegram-7d.csv` и `.md` в `artifacts/`.

**3. Лендинг — готовый файл, а не «пример кода»**

```
> сделай лендинг для студии йоги

Собрал лендинг. Тема: студия йоги.
- Файл: `landing-studii-jogi.html` — открывается в браузере, без сборки.
- Что внутри: первый экран, 3 блока выгоды, «как это работает», тариф, CTA, подвал.
```

**4. Маркетинг — воронка считается, бюджет делится в рублях**

```
> придумай рекламную кампанию для языковой школы на 50000 рублей

## 3. Каналы и бюджет (всего 50 000 ₽)
| Канал | Доля | Сумма | Зачем |
| Платная реклама | 40% | 20 000 ₽ | быстрый трафик и заявки |
| Контент и соцсети | 25% | 12 500 ₽ | органика, охваты, доверие |
| CPL: 500 ₽ = бюджет / 100 заявок; CAC: 3 333 ₽ = бюджет / 15 сделок
```

**5. Дизайн — промпт, который не стыдно вставить в генератор**

```
> промпт для картинки: уютная кофейня у моря на рассвете

Объект: уютная кофейня у моря на рассвете
Промпт: уютная кофейня у моря на рассвете. editorial illustration, confident line work,
limited palette, textured shading. cozy, intimate, warm. ...
Negative: photo, text, muddy colors, noise
```

**6. Видео — раскадровка по секундам + промпт для генератора**

```
> раскадровка для видео о запуске курса

| 1 | 0–3,8 с | медленный наезд (push-in) | общий план: о запуске курса в естественной среде |
| 2 | 3,8–7,6 с | панорама слева направо | деталь: крупный план фактуры и материала |
```

**7. Тексты без LLM — честный каркас, а не выдумка**

```
> напиши пост про открытие кофейни на набережной

Открытие кофейни на набережной
Рассказываем, что за этим стоит и почему это стоит вашего внимания.
...
Пометки: LLM не подключена (нет LLM_API_KEY) — показан офлайн-каркас
```

Пометка внизу — принципиально: лучше показать скелет и сказать об этом, чем выдать шаблон за готовый текст.

**8. Работа с текстом — выжимка и задачи**

```
> сократи: Выручка выросла на 30 процентов за квартал. Команда расширилась до 12 человек...

**Главное**
- Выручка выросла на 30 процентов за квартал.
- Команда расширилась до 12 человек.
- В следующем году выходим на новый рынок.
```

**Если роутер ошибся** — укажите специалиста вручную:

```bash
python3 -m veselovskaya ask "разбери этот текст по тезисам" --skill assistant
python3 -m veselovskaya route "что выберет роутер"   # показать решение и веса
```

## Запуск как сервис

```bash
python3 -m veselovskaya serve --port 8000
```

- `GET /` — чат в браузере (тёмная тема, кнопки-примеры, скачивание файлов)
- `POST /chat` — `{"text": "...", "platform": "web"}`
- `GET /health`, `GET /skills`, `POST /route`, `GET /files/{name}`

```bash
curl -s localhost:8000/chat -H 'Content-Type: application/json' \
     -d '{"text":"сделай лендинг для кофейни"}'
```

Docker:

```bash
docker build -t veselovskaya .
docker run -p 8000:8000 --env-file .env veselovskaya
```

systemd (юнит в `deploy/veselovskaya.service`) — для постоянной работы на сервере.

## Как добавить своего специалиста

```python
# veselovskaya/skills/yours.py
from ..types import Result, Task
from .base import Context, Skill

class RecipeSkill(Skill):
    name = "recipe"
    title = "Рецепты"
    description = "Подбор рецептов по продуктам"
    patterns = [(r"рецепт|что приготовить", 6)]

    def run(self, task: Task, ctx: Context) -> Result:
        return Result(text=f"Готовлю идею под: {task.text}", skill=self.name)
```

Добавьте класс в `build_skills()` (`veselovskaya/skills/__init__.py`) — роутер подхватит его сам.

## Границы, о которых честно

- Видео ассистент **проектирует** (раскадровка, промпт, тайминги), но не рендерит:
  рендер — отдельный тяжёлый сервис, подключается как ещё один провайдер.
- Качество свободных текстов = качество подключённой LLM. Без ключа — каркас, а не «средний текст».
- Расчёты не используют LLM вообще — поэтому не врут.
- Подключение платных API — ваши ключи и ваш расход; бесплатные тарифы работают без оплаты,
  но с лимитами по частоте запросов.
- Свободный текст бесплатен настолько, насколько бесплатен выбранный тариф: качество зависит
  от модели, а не от цены — Groq и Gemini на бесплатном уровне пишут лучше многих платных.
