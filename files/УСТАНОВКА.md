# Установка «Веселовской» на компьютер

Один архив, три системы. Ничего компилировать не нужно, всё ставится за один двойной клик.

---

## Что понадобится

- **Python 3.10 или новее** — бесплатный, ставится за 5 минут (ссылка ниже).
- **Интернет при первом запуске** — чтобы скачать две библиотеки (около 30 МБ). Дальше интернет
  нужен только для свободных текстов; расчёты, контент-планы, лендинги, промпты работают офлайн.
- Windows 10/11, macOS 12+, Linux.

## Что лежит в архиве

| Файл | Зачем |
|---|---|
| `veselovskaya.pyz` | сам ассистент, весь код в одном файле |
| `start-windows.bat` | запуск на Windows (двойной клик) |
| `start-macos.command` | запуск на macOS |
| `start-linux.sh` | запуск на Linux |
| `ПАМЯТКА.md` | шпаргалка: что писать, чтобы получить нужный результат |
| `README.md` | полное описание возможностей и настроек |
| `.env.example` | шаблон настроек: ключи LLM, адрес сервера |

## Windows 10/11

**Шаг 1. Поставить Python** (если ещё нет).
Скачайте с https://www.python.org/downloads/ → кнопка «Download Python 3.12.x».
В установщике **обязательно** отметьте галочку **«Add python.exe to PATH»**, затем «Install Now».

Проверить: откройте «Командную строку» (Win+R → `cmd` → Enter) и введите:

```
py -3 --version
```

Должно ответить `Python 3.12.x` (любая версия 3.10+).

**Шаг 2. Распаковать архив.** Правый клик по zip → «Извлечь все» → папка на рабочем столе.

**Шаг 3. Двойной клик по `start-windows.bat`.**

Что произойдёт:

1. чёрное окно напишет «Первый запуск: готовлю окружение» (1–2 минуты);
2. скачаются библиотеки;
3. откроется браузер с ассистентом по адресу `http://127.0.0.1:8000`;
4. на рабочем столе появится ярлык **Veselovskaya** — дальше запускать можно им.

**Окно с консолью закрывать нельзя** — в нём работает ассистент. Свернуть можно.
Закрыли окно → ассистент остановился, данные никуда не пропали.

## macOS 12+

**Шаг 1. Проверить Python.** Откройте «Терминал» (Программы → Утилиты → Терминал):

```bash
python3 --version
```

Если версия ниже 3.10 или команда не найдена — поставьте Python с https://www.python.org/downloads/macos/
(пакет `.pkg`, обычная установка двойным кликом).

**Шаг 2. Распаковать архив** двойным кликом.

**Шаг 3. Запуск.** Проще всего — в Терминале:

```bash
cd ~/Downloads/veselovskaya-2.2-kit
bash start-macos.command
```

Либо двойной клик по `start-macos.command` в Finder. Если macOS скажет, что файл «от
неизвестного разработчика», выполните один раз в Терминале:

```bash
xattr -d com.apple.quarantine start-macos.command
```

**Шаг 4.** Браузер откроется сам. Адрес — `http://127.0.0.1:8000`.

## Linux

```bash
unzip veselovskaya-2.2-kit.zip -d veselovskaya
cd veselovskaya
bash start-linux.sh
```

Если Python нет: `sudo apt install python3 python3-venv` (Debian/Ubuntu),
`sudo dnf install python3` (Fedora). После первого запуска в меню приложений появится
пункт **«Веселовская»**.

## Куда всё ставится

| Что | Где |
|---|---|
| окружение и ассистент | `~/.veselovskaya/` (Windows: `%LOCALAPPDATA%\Veselovskaya`) |
| файлы, которые создаёт ассистент | `artifacts/` рядом с местом запуска |
| настройки (ключи, порт) | файл `.env` рядом с `start-*` или переменные окружения |

Занимает около 60 МБ. Удаление — просто удалить папку `~/.veselovskaya` и сам архив.

## Что работает сразу, без ключей и интернета

- расчёты: скидки, проценты, ипотека, маржа, НДС, зарплата на руки, вклады;
- контент-план на неделю/месяц и тексты постов;
- структура и тексты лендинга;
- промпты для картинок и видео, раскадровки, сценарии Reels;
- разбор задачи «кому это отдать» — маршрутизация по 11 специалистам.

Свободный текст (письма, статьи, длинные ответы) делает LLM. Бесплатные варианты —
OpenRouter, Groq, Gemini, Mistral, Cerebras или локальная Ollama: см. `README.md`,
раздел «Бесплатные тексты», и `python veselovskaya.pyz providers`.

## Обновление

Скачайте новый `veselovskaya.pyz` и положите его в папку с `start-*`, заменив старый.
Скрипт запуска сам скопирует свежую версию в `~/.veselovskaya` и перезапустит ассистент.

## Если что-то не так

| Симптом | Что делать |
|---|---|
| «Python не найден» | переустановите Python с галочкой «Add python.exe to PATH», перезапустите окно |
| «Не получилось скачать зависимости» | проверьте интернет/прокси, запустите снова; в корпоративной сети может мешать фильтр |
| Браузер не открылся | откройте вручную адрес из консоли, обычно `http://127.0.0.1:8000` |
| «address already in use» | не бывает: если порт занят, ассистент берёт следующий и пишет адрес в консоль |
| Windows ругается на `.bat` | «Подробнее» → «Выполнить в любом случае»: файл не подписан, но это обычный текстовый скрипт |
