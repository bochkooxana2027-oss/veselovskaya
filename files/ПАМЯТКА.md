# Веселовская — памятка

Одна страница, чтобы начать. Технические детали — в `README.md`.

---

## Что это

Ассистент, который **сам выбирает специалиста** под задачу: посчитает, напишет, соберёт
контент-план, сделает лендинг, подготовит промпт для картинки или раскадровку видео.
Не «одна модель на всё», а оркестратор: расчёты — вычислитель, контент — алгоритм,
тексты — LLM (если подключить), картинки и видео — внешние генераторы.

Работает **без ключей и без интернета**: расчёты, контент-планы, лендинги, промпты,
раскадровки, выжимки. Свободные тексты без ключа отдаются структурным каркасом с
честной пометкой — не выдумкой.

## Три способа запуска

### 1. Один файл, ничего ставить не надо

```bash
python3 veselovskaya.pyz ask "15% от 4800"
python3 veselovskaya.pyz chat
```

Нужен только Python 3.9+. Всё.

### 2. С веб-чатом (рекомендую)

```bash
./install.sh     # один раз: окружение + зависимости
./start.sh       # запускает чат и открывает браузер
```

Адрес: `http://127.0.0.1:8000`

### 3. Docker

```bash
docker build -t veselovskaya .
docker run -p 8000:8000 --env-file .env veselovskaya
```

## Бесплатные тексты: 2 минуты, без карты

Свободные тексты (посты, статьи, письма) можно писать бесплатно. У Groq, Gemini,
OpenRouter и ещё нескольких провайдеров есть бесплатный тариф: регистрируетесь,
получаете обычный API-ключ, кладёте в `.env` — всё.

```bash
python3 -m veselovskaya providers        # список вариантов и что уже найдено
```

Самый простой путь — Groq ([console.groq.com/keys](https://console.groq.com/keys)):

```bash
echo 'GROQ_API_KEY=gsk_ваш_ключ' >> .env
python3 -m veselovskaya doctor           # «бесплатный тариф Groq · модель llama-3.3-70b»
```

Ассистент сам находит любой доступный бесплатный ключ — OpenRouter, Groq,
Gemini, Mistral, Cerebras — или локальную Ollama, если она запущена. Ничего
настраивать не нужно; порядок виден в `providers`.

Совсем без аккаунтов — локальная модель (нужно 8 ГБ ОЗУ):

```bash
ollama serve && ollama pull qwen2.5:7b
```

**Своя модель** (если хочется платную или свой прокси) — кладёте в `.env`:

```env
LLM_API_KEY=sk-...                       # OpenAI / DeepSeek / что угодно совместимое
LLM_BASE_URL=https://api.openai.com/v1
LLM_MODEL=gpt-4o-mini
```

Если задан `LLM_BASE_URL`, бесплатный автоподбор не вмешивается.
Отключить его совсем: `VESELOVSKAYA_FREE=0`.

## Если что-то не так

| Симптом | Что сделать |
|---|---|
| «Думаю…» и ошибка связи | сервер не запущен: `./start.sh` |
| Ответ не тот специалист | уточните: `... --skill calc` (или `--skill text`) |
| Текст пришёл «каркасом» | бесплатная модель не найдена: `providers`, затем ключ в `.env` |
| Ответ «модель недоступна» | кончился лимит тарифа или сменилось имя модели: `LLM_MODEL=...:free` |
| Порт занят | `PORT=8010 ./start.sh` |
| Хочу посмотреть, куда уйдёт запрос | `python3 -m veselovskaya route "текст"` |

## Чего продукт не делает (честно)

- Не обучался на ваших данных — это не «своя нейросеть», а оркестратор поверх моделей.
- Видео не рендерит сам: собирает раскадровку и промпт для Kling/Veo/Sora.
- Без ключа LLM не пишет длинные свободные тексты — только каркас.
- Бесплатные тарифы ограничивают частоту запросов; для объёма нужен свой ключ.
- Не заменяет бухгалтера и юриста: считает по формулам, но нормы и законы проверяйте.
